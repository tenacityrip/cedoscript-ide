# CLAUDE.md

Two editor extensions over one set of typings.

## Mental model

- `typings/` is the source for both. `cedoscript.d.ts` and `capabilities.json` are generated by
  `scripts/sync-typings.mjs`; change the script, never the output.
- `vscode/src/capabilities.ts` and `intellij/.../Capabilities.kt` hold the same check. Change both, and both tests.
- `vscode/src/extension.ts` is the only file that imports `vscode`; everything else runs under `node --test`.
- `tests/sample.js` is type-checked against the typings with `strict`.

## Rules

- Capability gating is a property of the client. Do not guess which members are gated.
- No network access in either extension. Files are written only under `.cedoscript/`, plus `jsconfig.json`.
- Commits follow Conventional Commits and carry no AI-attribution trailers. You own every commit.
