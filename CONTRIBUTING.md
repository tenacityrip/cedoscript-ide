# Contributing

1. Run the checks in the README before opening a pull request.
2. A change to the capability check changes both implementations and both tests.
3. Typing mistakes: fix `scripts/sync-typings.mjs`, not the generated file, or open an issue.

Commits follow [Conventional Commits](https://www.conventionalcommits.org/), with no AI-attribution trailers. You are
responsible for every commit you submit.
